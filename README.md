# Paperents Android

Projeto Unity recuperado do build Windows de Paperents para adaptação e compilação Android.

## Versão Unity

`2022.3.36f1`

## Estrutura

- `Assets/`: cenas, scripts, prefabs, modelos, materiais, texturas, áudio e vídeos recuperados.
- `Packages/`: dependências do projeto exportado.
- `ProjectSettings/`: configurações recuperadas da build.

## Próximas etapas

1. Abrir o projeto na Unity 2022.3.36f1.
2. Verificar referências e scripts decompilados.
3. Adaptar mouse/teclado para controles touch.
4. Configurar Android ARM64 e IL2CPP.
5. Gerar APK pelo Unity Build Automation.

Este repositório é privado e deve ser usado somente com autorização sobre o jogo e seus assets.
